Two ways a reminder went missing

TLC walked every path through the reminder checker, snoozes, and sync from a second device. Before the fix, two paths mark a reminder shown before its time comes, so it never shows.

Bug 1 · sync

Another device moves the due date

The reminder shows here, then another device moves the due date later. The pull kept this device's notificationSent, so the new reminder never came.

Now a pull that moves the due date resets it, the same way a local edit does.

Bug 2 · snooze

A snooze ends before the reminder time

The checker fired when the snooze ended and marked the task shown, so the reminder at its own time never came.

Now an early snooze end fires nothing, and the reminder comes on time.
