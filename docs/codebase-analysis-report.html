Detailed findings

The Medium ledger is closed; four Low follow-ups remain.

Locations are current-source locations. The two closures are backed by fresh unit, production-build, and three-browser evidence.

Resolved · OBS-01 — smoke results now fail closed on blocking browser evidence

Confidence: HighVerification: 13 focused testsDimension: Error handling and observability

Resolution. hasBlockingPageEvidence() now treats console errors, page errors, and failed requests as failures for both verification and smoke reports. The formatted smoke output lists every blocking evidence class, so command output and exit status agree.

Evidence. New tests cover failed requests, a passing journey with blocking evidence, and display of all three evidence counts. bun run test -- --coverage passed 2,638 tests.

Location. tools/stagehand/report.ts; tests/tools/stagehand-report.test.ts.

Resolved · TEST-01 — a real production PWA lifecycle gate now runs in every browser lane

Confidence: HighVerification: Chromium · Firefox · WebKitDimension: Test quality and E2E health

Resolution. A serialized static-export runner permits the actual worker, waits until the page is controlled, verifies page/runtime caches and that an authorized /api/ probe was not cached, stops the origin server, then reloads the cached app. It exposed and fixed the previously uncached startup theme-init.js asset.

Evidence. bun run test:pwa -- chromium firefox webkit passed locally. CI builds the static export and runs the matching browser's PWA lifecycle check in each E2E matrix lane; the existing fixture-based install UI tests remain fast and isolated.

Location. scripts/verify-production-pwa.cjs; public/sw.js; public/sw-cache-logic.js; .github/workflows/ci.yml.

Low OBS-02 · The new smoke runner does not reliably terminate after a green run

Confidence: MediumEffort: SmallDimension: Tooling and reliability

Evidence. This audit's run printed all six PASS rows and wrote its evidence report, then remained running for more than 15 seconds after harness.close(); it required an interrupt and therefore ended with exit 130. The observable behavior means the command is unsuitable as a reliable blocking gate until open handles are resolved. The source sets process.exitCode but does not verify that the Stagehand/browser lifecycle has released the event loop.

Location. tools/stagehand/smoke.ts:82-99; tools/stagehand/harness.ts:139-145.

Recommendation. Diagnose open handles after Stagehand.close() and close the responsible client/transport. Add a subprocess test with a bounded timeout that fails if a passing one-journey run does not exit 0. Avoid a blind forced process.exit(), which can discard evidence writes.

Low TEST-02 · One Chromium design-lab check timed out in the latest parallel sweep

Confidence: MediumEffort: SmallDimension: Test quality and E2E health

Evidence. The latest canonical three-browser invocation passed 269 of 270 cases. Chromium timed out waiting for the “Clear search input” button in the design-lab keyboard/search scenario; Firefox and WebKit passed the same scenario. An immediate five-repeat Chromium run passed 5/5, which supports flakiness rather than a deterministic product regression but does not erase the failed canonical result.

Location. tests/e2e/design-lab.spec.ts:119-140.

Recommendation. Reproduce under the canonical seven-worker load, then replace the vulnerable readiness assumption with a stable UI-state wait. Keep the test failure visible until a full canonical run is clean.

Low SEC-01 · MCP troubleshooting paths disclose configured PocketBase hosts

Confidence: HighEffort: SmallDimension: Security and privacy

Evidence. The MCP trust-boundary contract says configured backend hosts must be redacted from diagnostics. The supported validation CLI prints the configured URL on successful and failed connectivity checks, and the setup preview prints it again. A legacy environment check also logs the raw value. Tokens are redacted; the host is not. This is a privacy/operational-information disclosure in terminal scrollback, logs, and screenshots rather than an authentication bypass.

Location. packages/mcp-server/src/cli/validation.ts:44-65, packages/mcp-server/src/cli/setup-wizard.ts:123-151, and packages/mcp-server/test-env-vars.js:15-17.

Recommendation. Reuse redactPocketBaseHost() for all user-visible CLI output, remove the raw-value legacy script or make it print only “set”, and add regression tests for both success and failure paths.

Low MAINT-01 · The shape gate preserves a large exception inventory

Confidence: HighEffort: LargeDimension: Maintainability and architecture

Evidence. The ratchet passes, so this is managed debt rather than a gate failure. It still permits 38 cyclomatic-complexity violations, four nesting-depth violations, and 113 functions over the 40-line target; the largest recorded function is 269 lines. This makes the matrix shell, PWA registration, dialogs, and sync/MCP write surfaces disproportionately expensive to change and test.

Location. scripts/code-shape-debt.json:1-15; measured by scripts/check-code-shape.cjs:32-107. Representative hotspots: components/matrix-simplified/index.tsx, components/matrix-simplified/capture-bar.tsx, components/pwa-register.tsx, and lib/sync/.

Recommendation. Retire exceptions by ownership domain, starting with testable state/side-effect extraction in PWA registration and matrix interaction hooks. Do not bulk-refactor; require a net decrease per affected feature and review the ledger quarterly before its 2026-12-31 expiry.
