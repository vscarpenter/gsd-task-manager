TEST-02Medium

Native Request equality produces a false privacy-test failure

Confidence: High·Effort: Small·Primary dimension 2

tests/data/service-worker-privacy.test.ts:182 · tests/data/service-worker-privacy.test.ts:180 · public/sw.js:65 · public/sw-cache-logic.js:87

Mechanism
The activation privacy test uses toHaveBeenCalledWith to distinguish native Request objects. In current Node26.9.0/Vitest4.1.11 these distinct Requests compare deeply equal even when URLs differ, so the negative assertion fails despite the worker retaining the safe URL. Recommendation
